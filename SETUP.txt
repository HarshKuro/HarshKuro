SETUP (2 minutes)
1. Create a PUBLIC repo named exactly: HarshKuro
2. Upload everything in this folder to the repo root on branch "main"
   (README.md, assets/, scripts/, .github/)  -- make sure the hidden .github folder goes up too
3. Repo -> Settings -> Actions -> General -> Workflow permissions -> "Read and write permissions"
4. Repo -> Actions tab -> "Update profile stats" -> Run workflow (it then refreshes every 6 hours)
5. On your GitHub profile, enable "Private contributions" so private work shows in the heatmap.
